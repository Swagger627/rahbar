## Important limits
- The approval on main must come from someone other than the author. Today the only other collaborator is
  MugheesHiader476 (write access). Nobody has approved anything, and no approval was faked.
- The owner plans to make the repository PRIVATE again. On a free plan, a private repository's protection rules
  are kept but NOT enforced (that is what Step 5.2 measured). Enforcement then returns only with public visibility
  or GitHub Pro. GitHub Pro enforces the same rules on private repositories: the 403 disappears, and the rules
  above would apply as they do today.
